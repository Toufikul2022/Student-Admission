Home page photos. The file name must START with the slot name:

  hero-....webp    – top banner (transparent cut-out of a person works best)
  steps-....webp   – "Your study steps" section (transparent cut-out works best)
  banner-....webp  – the promo banner, right side (normal photo, shown in a frame)
  form-....webp    – next to the "Speak to an advisor today" form (normal photo)

To change a photo: delete the old file and upload the new one with a NEW name,
e.g. replace "hero-1a2b3c4d.webp" with "hero-2027.png". A new name makes sure
browsers and Vercel's image cache show the new photo straight away.
.webp, .png, .jpg and .jpeg all work. Use photos at least 1200px wide/tall
for sharp results, and only photos you have the rights to use.
