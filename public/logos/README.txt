Institution logos.

Name each file with the institution's "slug" from data/institutions.json, for example:
  university-of-manitoba.svg
  red-river-college-polytechnic.png
  university-of-winnipeg.webp

It appears automatically on cards and the institution's page the next time the site
builds (on Vercel: as soon as you upload it to GitHub). Until then, initials are shown.

To replace a logo, upload it with a NEW name that still starts with the slug
(e.g. university-of-manitoba-2027.svg) and delete the old file, so browsers show the new one.

Tips: SVG or a transparent PNG works best, at least 200 px wide. Only use logos you have
permission to use (ask each institution's marketing or international office).
